# WebUI 单页化与功能清理设计

## 目标

AstrBot 只发现 `pages/a_manage/` 这一个业务 Page。管理、表情索引和设置中心作为同一份 HTML 的三个视图，通过 `#manage`、`#index`、`#settings` 切换；页面内不读取、复制或拼接静态资源令牌。

## 页面结构

- 顶部提供三个可键盘访问的 hash 导航入口，并使用 `aria-current` 标记当前视图。
- `router.js` 负责未知 hash 回退、视图显隐、浏览器前进/后退和幂等初始化。
- `managed_pack_id` 始终保存在查询参数中；三个视图切换 pack 时共享更新该参数。
- 管理页、索引页和设置页的样式分别由基础样式、`capture-index.css` 和 `settings.css` 承担，后两者只服务各自视图。

## 功能边界

- 移除资源广场页面、导航、首次使用引导和静态资源；社区后端接口不变。
- 移除管理页批量工具栏、批量上下文菜单、批量移动弹窗和选择状态。
- 移除索引页重复项批量选择；保留单项忽略与“全部忽略重复记录”。
- 设置中心保留选择规则、单包迁移、全量备份/还原和操作日志。
- 已分类表情分页位于已分类卡片列表之后；待分类列表完整显示且不计入分页摘要。

## 兼容性

后端 Web API、配置 schema、pack 数据结构、社区接口和批量服务接口均不修改。单项移动继续以单文件负载调用现有移动服务。
